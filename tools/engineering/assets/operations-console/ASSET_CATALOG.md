# Operations Console asset catalog

| Asset | Intended use | Theme |
| --- | --- | --- |
| `icon-dark.png` | Master icon for dark chrome, splash screens and PWA packaging | Dark |
| `icon-light.png` | Master icon for light chrome and light-mode browser tabs | Light |
