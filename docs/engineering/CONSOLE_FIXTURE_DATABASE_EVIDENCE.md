# Owned Console fixture database evidence

This is a fixture contract, not an alternate production reader or grant.
The old Q13 byte cause remains UNESTABLISHED; its missing bytes are not rebuilt.

T0 is captured before browser opening. T1 is captured on the actual owning SSE
read boundary using a short own-store SQLite RESERVED transaction. Actual SQL
writer statements and source owners are retained. Concrete capacity-history
observations and Console action audits may be replayed from T0, provided all
logical tables, schema and physical bytes match T1 exactly. Explicit labelled
configuration setup has its own narrow owner contract. Other changes fail;
no table or field is masked and no unobserved baseline is adopted.

T2 retains the moved source, physical identity and existing journal family
before restore. A replacement is separately retained and cannot be silently
overwritten: original publication uses a non-overwriting hard link. Mutation
of the moved source fails and it is not published as the original. Restored
bytes and identity are independently retained.

Product audit and HTTP/SSE outcome stay real. Fixture invariant/retention
failures are recorded before recovery and yield an unsuccessful worker verdict
after the native browser control/stream result is observable. Evidence remains
outside the own-store cleanup root. If retention fails, the own source is kept;
the listener/process must still stop. No ordinary exception is declared benign.

Shutdown closes request admission and waits for every ordinary handler under
the existing five-second bound. Provider guards remain installed through actual
worker exit, including sleeping SSE handlers. The browser owner observes child
close, verifies the own-store marker, retains closed-process database files,
and compares their hashes, size and identity with the last consistent snapshot.
A difference remains red and preserves the own-store. Only complete, matching
evidence permits cleanup after process stop. The original worker closure and
separate post-close receipt remain truthful about their respective boundaries.
