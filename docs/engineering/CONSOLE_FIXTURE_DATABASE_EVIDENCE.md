# Owned Console fixture database evidence

This is a fixture contract, not an alternate production reader or grant.
The old Q13 byte cause remains UNESTABLISHED; its missing bytes are not rebuilt.

T0 is captured before browser opening. T1 is captured on the actual owning SSE
read boundary using a short own-store SQLite RESERVED transaction. Actual SQL
writer statements and source owners are retained. Concrete capacity-history
observations and Console action audits may be replayed from T0, provided all
logical tables, schema and physical bytes match T1 exactly. Explicit labelled
configuration setup has its own narrow owner contract. Other changes fail;
no table or field is masked and no unobserved baseline is adopted.

T2 retains the moved source, physical identity and existing journal family
before restore. A replacement is separately retained and cannot be silently
overwritten: original publication uses a non-overwriting hard link. Mutation
of the moved source fails and it is not published as the original. Restored
bytes and identity are independently retained.

Product audit and HTTP/SSE outcome stay real. Fixture invariant/retention
failures are recorded before recovery and yield an unsuccessful worker verdict
after the native browser control/stream result is observable. Evidence remains
outside the own-store cleanup root. If retention fails, the own source is kept;
the listener/process must still stop. No ordinary exception is declared benign.

Shutdown closes request admission and waits for every ordinary handler under
the existing five-second bound. Provider guards remain installed through actual
worker exit, including sleeping SSE handlers. The browser owner observes child
close, verifies the own-store marker, retains closed-process database files,
and compares their hashes, size and identity with the last consistent snapshot.
A difference remains red and preserves the own-store. Only complete, matching
evidence permits cleanup after process stop. The original worker closure and
separate post-close receipt remain truthful about their respective boundaries.

Partial worker startup retains its actual process owner before readiness.
Startup and teardown failures remain separate; a never-ready worker is not sent
a normal quiesce request. Native signal errors are recorded with the actual PID.
An exited-unreaped Darwin group may return EPERM after a real live poll: this is
classified as an exit race only after the actual child is reaped and a fresh
whole-group census proves no live members. A live descendant, an unavailable
census or a denied live child remains a cleanup failure. Guards and failuredata
stay retained until group death is proved. The unchanged terminate/kill budget
is two seconds. Old unrecorded EPERM causes are not retroactively established.

Python exception groups are ordinary failure evidence, including their distinct
traceback header, indented terminal and incomplete grouped traces. The raw log
collector rejects these after actual child close and retains every nested cause.
Positive in-process Console projection tests register their project through the
supported topology service before reading; project-list doubles do not grant
access. Withdrawal still stops projection before any private detail is returned.

The complete browser corpus is retained in the reviewed canonical inventory.
Playwright's contiguous count sharding placed every slow installed canary in
the first part and then appended an indivisible smoke hook group; the actual
300-second batch failed while the other three parts completed. The supported
reporter preprocess API now partitions each owning declaration file round-robin.
Four parts, one worker per part, retries, assertions and the 300-second batch
deadline remain unchanged. Both CI and local commands require this reporter;
caller reporter overrides are rejected. Canonical names, expected outcomes,
disjoint union, selected cases and actual terminal outcomes are mandatory gates.
A narrowed corpus, newly skipped case, outside error, missing completion or failed
attempt cannot qualify. List-only plans remain explicitly unqualified.
The four original worktree skip declarations remain bound to their original
case identities, status and normalized annotations and are reported separately
as baseline NOT_RUN. They are present in protected base; 509 active cases still
require successful real completion. A general allowance for skips is forbidden.
The historical SSE wrapper-source assertion is replaced with actual HTTP retry
and PROJECT frame observations against distinct CENTRAL/project policies. A
project-local reader trap remains armed; injecting that root policy must fail
the same wire assertion. Accepted handlers really stop before guard restoration.
