# Console terminal read scope

The presentation ID `none` is not authority. The server's explicit no-project
page flag selects PLATFORM; selected projects, including a real ID `none`,
retain PROJECT scope. Terminal controls carry `scope=PLATFORM, project_id=null`
or `scope=PROJECT, project_id=<exact nonempty selected ID>` respectively.
Missing, malformed, foreign and unknown controls are ignored without granting
rights. Valid terminal controls bypass ordinary auto-refresh preferences.
Stream ownership, document identity and read epoch remain required. Terminal
invalidation closes the actual EventSource, clears old data and prevents late
callbacks from restoring it. Source recovery requires a new authorised document.
